# visual-story-director 1.3.0 — 2026-10-05

По поручению владельца обновлён полный пакет
[visual-story-director](../../skills/visual-story-director/SKILL.md) из канонического
проекта навыков. Изменение касается текстового предпроизводства: содержательного
диалога, причинных связей, читаемой ASCII-раскадровки, состояний предмета,
копируемых заданий и режимов речи. Инструкции остаются независимыми от renderer.

## Состав и проверка

121 файл импортирован побайтно; прежние файлы не удалены. Добавлены четыре
вымышленных авторских образца и девять практических eval-сценариев в одном JSON.
Лицензии, provenance, схемы, код валидаторов и тесты сохранены. Каталог навыков
обновлён; соседние aimedia и infographic-designer не меняются.

Три независимых цикла SOL 6.1 завершились REVISE, REVISE, ACCEPT. Между циклами
исправлены скрытое причинное звено и двусмысленность narrator_only. Подробности,
охват задач и ограничения — в
[приёмке навыка](../../skills/visual-story-director/docs/acceptance.md).
Это приёмка инструкций для текстовой подготовки; учебный проект из испытания
остаётся draft с отмеченными source-pending механизмами.

Проверки выпуска: bundle и формат навыка, локальный профиль, 15 unittest-методов,
правка с baseline, проверка технических Markdown в хранилище; повторные проверки
импортированного пакета, относительные ссылки/YAML, git diff --check и офлайн-сборка
wheel/sdist из снимка подготовленного дерева Git. Полный пакет сверяется внутри
sdist по SHA-256; в wheel навыки по прежнему не входят. Снимок сборки исключает
постороннюю неотслеживаемую `.serena/`. Исходные команды, exit codes, инвентаризации
и независимый read-only review через native Pi / openai-codex / gpt-6.1-sol
сохраняются в локальном хранилище выпуска за пределами репозитория.

## Границы выпуска

Runtime, src, tests, pyproject.toml и uv.lock не меняются; версия CLI остаётся 0.1.0.
Полный runtime/OS suite не повторялся для этого документального изменения.
Генерация, TTS, платные Polza API, обновление установленного uv tool и глобальная
установка навыков не выполняются. Реального читательского испытания не было.

Владелец отдельно разрешил коммит и перенос тега релиза. В этом обновлении
переносится локальный аннотированный v0.1.0 на новый коммит; прежний объект тега
сохраняется в локальном журнале. Remote main, remote tag и опубликованные assets
не меняются. Этот отчёт не утверждает обновление публичного релиза или
установленного инструмента.
