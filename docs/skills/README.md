# Пакет навыков aimedia

Пакет находится в `docs/skills/` репозитория. Это самостоятельные инструкции
для агента, **не** встроенная справка CLI и **не** часть опубликованного
`uv tool` v0.1.0. Само расположение `docs/skills/` не включает autodiscovery Pi.

| Навык | Роль |
|---|---|
| [aimedia](aimedia/SKILL.md) | Практическая работа с установленным image CLI: генерация, создание референсов, поиск моделей/истории, анализ расходов |
| [visual-story-director](visual-story-director/SKILL.md) | Текстовое предпроизводство: история, персонажи, стиль, раскадровка, промпты и сценарии речи; без генерации image/audio/video |

## Как использовать

Передайте агенту путь к нужному `SKILL.md` и задачу; пусть прочитает навык.
Для standalone использования достаточно скопировать **целиком папку выбранного
навыка**, сохранив её относительные ресурсы. Навык `aimedia` требует установленную
команду `aimedia`, но не checkout, dev-окружение или остальные навыки.

В Pi можно явно подключить файл (команды ниже только инструкция по подключению):
из корня репозитория используйте точные пути:

```text
pi --skill ./docs/skills/aimedia/SKILL.md
pi --skill ./docs/skills/visual-story-director/SKILL.md
```

Вне репозитория передайте `--skill` фактический полный путь к скопированному
`SKILL.md`. Флаг повторяемый; загрузка содержимого затем доступна через
`/skill:aimedia` или `/skill:visual-story-director`. Никакой автоматической
установки или изменения глобальных/project settings пакет не делает.
Перед использованием проверьте содержимое; scripts — код, а не разрешение на запуск.

## Передача между навыками

`visual-story-director` передаёт готовый prompt или задание на референс.
Это **не** разрешение на платный запрос. `aimedia` отдельно согласует модель,
параметры, реальные входные файлы и бюджет. Речь в донорском `voice-script` —
только текстовая подготовка для отдельного исполнителя: aimedia не выполняет
TTS, аудио, видео, монтаж, text generation или embeddings.

`visual-story-director` 1.2.0 импортирован целиком и без редактирования.
Сохраняются [README](visual-story-director/README.md),
[Apache-2.0 LICENSE](visual-story-director/LICENSE),
[THIRD_PARTY_NOTICES](visual-story-director/THIRD_PARTY_NOTICES.md),
[licenses](visual-story-director/licenses/) и
[provenance](visual-story-director/provenance/upstream-lock.json), а также все
scripts/tests/examples. Донорские отчёты и evals — сведения донора, не доказательство
проверки aimedia или исполнения его scripts в этом репозитории.

Следующие навыки добавляются соседями: `<name>/SKILL.md` с YAML `name` и точным
`description`, ресурсы — относительными путями внутри той же папки. Сохраняйте
лицензии и уведомления. Не помещайте в пакет пользовательские проекты, prompts,
референсы, outputs, историю, конфигурацию или секреты; они хранятся в выбранных
пользователем внешних местах. Пакет не устанавливает зависимости или навыки.
Правила сопровождения — [DOCS.SkillPack](../../instructions/DOCS.skill-pack.instructions.md).
