# Render Brief Compiler

> АГЕНТ: ЧИТАЙ ЭТОТ ФАЙЛ ЦЕЛИКОМ ДО ПОСЛЕДНЕЙ СТРОКИ.

Это роль orchestrator. Скомпилируй проверенную семантику, visible wireframe,
выбранный style profile и medium/size в backend-specific инструкции.
Standard — раздел brief; strict — schema render-brief.yaml.

Включи immutable entity/edge IDs, exact text, values/units, critical direction
и containment, composition/reading order, style/reference roles, negative
constraints, dimensions, editable source и export, доступный fallback.

Для topology-critical visual structured skeleton владеет связями. Image backend
не перестраивает граф. Exact text при ненадёжном backend накладывается отдельным
редактируемым слоем. Render instructions не меняют смысловую модель или число
этапов ради style profile. Renderer thresholds — heuristics, не обещание fidelity.
