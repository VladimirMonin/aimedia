# implementation-decisions

**Основное ТЗ — план 1.0 от 2026-10-02.** Пользователь отдельно уточнил:
план первичен, учебная сессия вторична. Сессия даёт регрессионные ошибки,
но не отменяет ТЗ и не служит справочником по image-моделям.

| Решение | Причина |
| --- | --- |
| Одна точка входа и 18 условных руководств в 1.1 | Сохранить все W0–W9; процесс разработки и проверка понимания читаются по задаче |
| Самостоятельный пакет в папке проекта | Глобальная установка не заказана |
| Доноры — отдельные pinned snapshots | Пользователь заказал скачивание; переносимость не требует их установки |
| Текстовые JSON-контракты и Markdown-представление | Не строить базу промптов и историю медиазапусков |
| Полная библиотечная JSON Schema + свой semantic pass | Не выдавать частичный самодельный JSON checker за полный стандарт |
| Python 3.10+, jsonschema 4.26.0 только для проверок | Творческий режим не требует runtime-зависимостей |
| old_value по ContextDelta сверяется с ProjectContext | Обнаруживать устаревший канон |
| old_value targeted_revision сверяется с --baseline | Без прошлого документа честно выдаётся skipped warning |
| Нет собственных сетевых API, генераторов, очередей и persistence | Последнее уточнение границ плана |
| Авторские примеры отдельно от реальных прогонов | Эталон не равен поведению агента |
| Нормализованные координаты | Проверяемое намерение без обещания пиксельной точности |
| Apache-2.0 для собственных частей; сохранены MIT и Apache notices | Умолчание плана; корневые правила vault не переоформлялись |
| Нет обязательных баннеров чтения и блокировки по 300 строкам | Явное уточнение пользователя; полнота сложного руководства важнее искусственного лимита |

Из сессии сохранены случаи: иллюстрации вместо страницы комикса; лишняя выдача
после «только один промпт»; подмена обсуждения героев генерацией; незапрошенная
смена стиля; отвлечённый опыт вместо задачи персонажей; изменение реплики при
озвучке; немые герои без искусственных голосов. Их содержание встроено в
режимы, рубрику и матрицу E01–E32, без частных пользовательских персонажей в пакете.

ID ограничены kebab-case, а mode сохраняет narrator_only и другие имена из ТЗ.
Редакции — строки: draft-01, context-01. Это метаданные передаваемых документов,
не обещание системного version control. Формальные тесты и независимый forward-test
различаются; автоматическое обнаружение навыка в разных host не измерялось.

## Уточнение методики в 1.1

Обратная связь о визуальных пробах выявила различие между корректным перечислением
тем и понятной историей. Формальные проверки и общая рубрика не обнаруживали,
что часть причинных связей существует лишь в рабочих заметках. Поэтому добавлены
проверяемые переходы между этапами и отдельное чтение с позиции зрителя.

Из предоставленного пользователем алгоритма работы с лекциями адаптирован принцип:
декомпозиция содержания до компоновки, проверка покрытия, локальная и общая оценка,
возврат к этапу, на котором возник дефект. Числовые нормы и структура учебной статьи
не перенесены. Тексты руководств написаны для визуальных историй заново; исходные
частные документы не включены и не нужны установленному навыку.

Новые смысловые карты остаются редакторским методом, а не дополнительным обязательным
JSON-протоколом. Узкие режимы и принятый канон сохраняют прежнюю область действия.
Проверка различает достаточную ясность, жанровую недосказанность и случайный пробел;
она не требует учебного объяснения от атмосферного фрагмента или шутки.

## Уточнение критериев в 1.2

Диалоговый текстовый пилот выявил ошибку классификации: общее название операции
было признано допустимым упрощением без формул, хотя недоставало качественной связи
между действием и результатом. Уточнены существующие руководства, а не создан
новый обязательный процесс. Глубина определяется обещанием зрителю; проверка общих
слов требует конкретного основания, но не запрещает слова как таковые.

Необходимость повторов и оговорок проверяется по их функции. Нужные ограничения
точности сохраняются в зрительском материале, художественная пауза не обязана
сообщать факт. Самостоятельная попытка героя требуется выбранному исследовательскому
сюжету, а не каждому комиксу. Понятное объяснение не считается доказанным развлечением.

Диалог уточняет форму и глубину и показывает последствия обратной связи.
Автономность не требует ожидания ответа; узкая правка не запускает весь процесс
заново. Подтверждённые дефекты отделяются от гипотез о читательской реакции.
