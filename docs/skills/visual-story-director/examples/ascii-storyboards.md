# ascii-storyboards

**Авторские образцы оформления.** Сетка и число моментов относятся только к
данным сценам. ASCII обозначает приблизительное расположение, не точную геометрию.

## Страница с последовательными панелями

Правило вымышленного мира: зелёная лампа двери показывает питание, засов — замок.
Назначение страницы: герой различает эти два состояния после неудачной попытки.

```text
СТРАНИЦА: порядок чтения 1 -> 2 -> 3
+-------------------------------------+
| 1. Герой видит зелёную лампу          |
|    и берётся за ручку.               |
+------------------+------------------+
| 2. Дверь стоит.   | 3. Крупно: лампа  |
| Рука тянет ручку.| зелёная, засов    |
| Лицо удивлено.   | всё ещё закрыт.  |
+------------------+------------------+
```

| Панель | Действие и акцент | Точный зрительский текст | Доступный вывод |
| --- | --- | --- | --- |
| 1 | Взгляд на зелёную лампу, рука на ручке | Облачко героя: «Зелёный! Можно идти» | Герой ожидает открытую дверь |
| 2 | Ручка под усилием, дверь не сдвинулась | Без текста | Ожидание не сработало |
| 3 | Лампа и закрытый засов рядом; два указателя | Подписи: «Питание есть», «Замок закрыт» | Это разные состояния |

Переход: на следующей странице герой меняет состояние засова и проверяет результат.
Локальная проверка: видимость закрытого засова нужна уже в третьей панели.
Если читателю показана только реакция, объяснение ещё не состоялось. Пример
не приказывает растянуть любое действие на три панели или несколько страниц.

## Один момент в одиночном изображении 16:9

Назначение: показать обнаружение различия в тот момент, когда герой указывает
на закрытый засов. Это альтернативная постановка того же обнаружения, не следующая
страница и не дополнительное событие в предыдущей сетке.

```text
ОДНО ИЗОБРАЖЕНИЕ: A, B, C существуют одновременно
+---------------+-------------------------+
| A. Герой      | B. Дверь: зелёная лампа, |
| смотрит на    | крупный закрытый засов. |
| засов, палец  |                         |
| направлен к B.| Подписи около объектов. |
+---------------+-------------------------+
| C. Свободная нижняя область: порог двери|
+-----------------------------------------+
```

**Действие:** герой остановился и показывает на засов. **Акцент:** засов и лампа,
затем лицо. **Текст:** «Питание есть» возле лампы, «Замок закрыт» возле засова;
это подписи без хвостиков. **Опора:** одновременно показанные разные признаки.
**Переход:** дальнейшая попытка открывания требует следующего изображения.

Для промпта заказывается одна иллюстрация без панели-сетки. Зоны A/B/C служебные,
их буквы не рисуются. Нет последовательности «герой подошёл, проверил и прошёл»
в одном моменте. Если нужен весь процесс, меняется постановка и число изображений.

## Проверка полезности карточки

Плохо: «Герой осознал принцип замка; зритель теперь всё понимает».
Исправление: описать доступные признаки, точный текст и направление взгляда.
Если правило уже показано раньше, подписи можно убрать после проверки достаточности
контекста. Удаление нужного текста ради эстетики не считается улучшением ясности.

## Когда сравнение ещё не объясняет причину

Дополнительное правило вымышленного мира: автоматический замок сравнивает код
предъявленной карты с разрешённым кодом; при совпадении отводит засов.

Недостаточно для обещания «объяснить почему»: герой меняет карту, дверь открывается,
подпись «Карта направляет работу замка». Зритель увидел зависимость, но не действие,
которое связывает карту с засовом. Рабочая заметка автора это не исправляет.

Вариант объяснения: крупно «Карта: 42» и «Разрешённый код: 42»; подпись
«Замок сравнивает коды. При совпадении отводит засов»; затем засов в открытом
положении. Вопрос проверки: «Почему другая карта с кодом 17 не откроет дверь?»
Ответ опирается на показанное сравнение, а не только на фразу «умный замок».

Это правило данного мира, не утверждение о реальных дверях. Для технической
истории аналогичная связующая операция должна иметь источник. Обзор может
достаточно показать новую возможность; качественное объяснение выполняет другое
обещание. Не добавляй схему кодов в историю, где она не нужна.
