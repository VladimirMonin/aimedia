# project-context

**Контекст передаётся, а не хранится навыком.** ProjectContext содержит project_id,
context_revision, канон, карточки героев, style, voices, episode_summaries и open_threads.
Загружай выбранный проект и только относящиеся к выпуску сведения. В диалоге
достаточно компактного снимка; обязательное дерево папок не создаётся.

Похожие имена в двух проектах не доказывают идентичность. Персонаж «Пик» на колёсах
из мастерской не наследует крылья лесного «Пика». Перенос возможен только по явному
решению: cross_project_permissions содержит source_project_id и approval=approved.
Импортированная карточка получает локальный project_id и origin_project_id.

Для продолжения используй итог релевантного выпуска и незакрытые линии.
При отсутствии финала назови пробел. Не заимствуй его из соседнего проекта.
Можно подготовить независимое событие с допущением, не требующее неизвестного факта.
Отсутствие сведений о событии не доказывает, что оно не происходило. Если проверка
крепления не описана, пиши «сведения о проверке отсутствуют», а не «крепление не
проверяли». Новый сюжет может предложить повторную проверку без выдуманного прошлого.

ContextDelta включает project_id, base_revision, approval и changes. Для каждой
правки: entity_type, entity_id, field, old_value, new_value, reason. Изменение
события выпуска не превращается в постоянную черту характера. Для принятой
карточки сохраняй старое значение и базовую редакцию; stale delta — конфликт.
Выход является предложением. Его применение, сохранение и выбор активной папки
принадлежат пользователю/host, без self-modification и скрытой записи в навык.
