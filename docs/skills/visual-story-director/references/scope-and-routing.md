# scope-and-routing

**Один результат навыка — предпроизводственное текстовое задание.** Идея, история,
персонажи, стиль, раскадровка, промпты и речь — его согласованные части.

| Внутри | Снаружи |
| --- | --- |
| Описать референс и его роль | Создать, скачать, скопировать или хранить изображение |
| Подготовить речь, роли и паузы | TTS, клонирование голоса, запись, выравнивание |
| Описать порядок показа | FFmpeg, Remotion, монтаж, рендер, субтитры из аудио |
| Сформировать ProjectContext / ContextDelta | Применить изменения к постоянному хранилищу |
| Проверить текст и доступные изображения по запросу | Объявить готовыми невиденные медиа |

Запрос «сгенерируй видео» не запускает API из этого навыка. Подготовь полезный
handoff и кратко обозначь внешний этап; не заявляй, что файл создан.
Не требуй устанавливать доноров, выбирать платный сервис или открывать `.env`.
Чтение данных и export штатным механизмом host допустимы в пределах текущего
поручения. Авторизация не переносится на публикацию и глобальную установку.

Навык не собирает пользовательские проекты в своей папке. Встроенные примеры —
вымышленные эталоны; фактические прогоны хранятся вне установочного пакета.
