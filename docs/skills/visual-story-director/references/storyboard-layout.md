# storyboard-layout

**Три масштаба:** композиция панели, композиция страницы, порядок показа во времени.
Страница не становится одной иллюстрацией потому, что генерируется одним файлом.
Одно изображение может содержать четыре последовательных момента в четырёх панелях.

| Формат | Постановка |
| --- | --- |
| Страница 9:16 | Вертикальные полосы и крупный текст; читается как один экран |
| Страница 16:9 | Широкая композиция, отдельное распределение панелей |
| single_panel | Один момент, без незапрошенных рамок |
| vertical_strip | Лента для прокрутки переменной длины; не один экран 9:16 |
| custom | Положительное отношение ширины и высоты, объяснённая композиция |

Начальные макеты: [layout-presets](../assets/layout-presets/presets.json).
Это редактируемые примеры, а не фиксированные сетки для любых историй.
На странице 9:16 три полосы могут иметь состав 1/2/1, итого четыре панели.
Порядок: верхняя, средняя левая, средняя правая, нижняя.

В JSON `rect: [x,y,width,height]` у панели задан относительно страницы,
а `text_zones[].rect` — относительно панели. Начало сверху слева. Все значения
конечны, размеры положительны, сумма координаты и размера не превышает 1.
Для намеренных пересечений перечисли пары ID в `allowed_overlaps` и дай причину.
Порядок чтения — полная уникальная последовательность 1..N отдельно от ID.

Для каждой панели укажи action, camera, focus, participants и beat_ids.
Каждая видимая строка связывается с текстовой зоной и говорящим. У `bubble`
`tail_to` указывает персонажа в панели; у `caption`/`label` хвостика нет.
Согласованный текст не исчезает при переходе к `external_lettering`.

Если надписей много, раздели действие, сократи с согласованием или отведи отдельный
показ. Не обещай конкретный шрифт, точные пиксели и читаемость невиденного результата.

## Постановка для обсуждения человеком

Используй компактную карточку: назначение; действие и изменение состояния;
композиция/камера/главный акцент; точные строки и их носитель; опора для вывода;
переход. Изображение, реплика, подпись и заказанная озвучка имеют разные функции.
«Зритель понимает X» не заменяет указания того, что он увидит или услышит.
Заметка об эмоции помогает режиссуре, но не становится самостоятельной сценой.

ASCII нужен, когда схема помогает обсудить расположение или порядок чтения.
Объяви её смысл: сетка последовательных панелей на странице либо одновременные
области одного изображения. Номера панелей показывают порядок, буквы областей —
пространство. Не превращай буквы автоматически в панели при составлении промпта.
Размеры в ASCII приблизительны; координаты при необходимости уточняются отдельно.

Для одиночного 16:9 изображения лучше выбрать один момент с ясным главным
объектом, чем поместить в него несколько последовательных действий под видом зон.
Предмет до/после можно показать одновременно как явное сравнение. Важный дефект
должен быть различим в предполагаемом размере просмотра, а реакция героя —
связана с этим дефектом. При нехватке места предложи крупный план или следующий
момент; не спасай объяснение микротекстом.

Два заполненных образца и адресная проверка — в
[ASCII-раскадровках](../examples/ascii-storyboards.md). Их сетка, размер и сюжет
не являются пресетом для других задач.
