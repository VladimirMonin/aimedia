# style-guide

**Авторский стиль имеет приоритет.** Не подменяй готовое руководство пресетом.
Из доступного изображения извлекай особенности только после реального просмотра;
если просмотр невозможен, работай с описанием и отметь ограничение.

Карточка задаёт технику, контур, геометрию форм, палитру, свет, тени, детализацию,
фактуры, фон, текст и запреты. Техника, настроение и компоновка — независимые решения.
Одно слово «кинематографично» не задаёт эти свойства. Стиль не меняет лицо героя.

Шесть оригинальных стартовых вариантов находятся в
[style-presets](../assets/style-presets/presets.json). Выбирай только подходящие:
2D-научная комедия, мягкая живописная история, журнальное объяснение,
контрастный графический роман, чистая линия, выразительная рисованная анимация.
У каждого есть конкретные правила линии, цвета, освещения, фона и текста.
Названия чужих франшиз и их герои не являются обязательными частями описания.

После выбора зафиксируй краткий точный стилевой блок. В переносимом промпте
повтори релевантные правила, в `with_context` назови реальный документ и способ
его передачи внешним исполнителем. Не обещай, что image API читает Markdown-файл.
Если пользователь просит не дублировать стиль и передаёт документ, не переописывай
его; пометь промпт зависимым от этого контекста.
