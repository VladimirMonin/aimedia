# WORKFLOW — Нативные Pi-сабы aimedia

- Основной кодер для реализации — нативный Pi `worker` на
  `ollama-cloud/deepseek-v4.1-flash`. Это не Ollama CLI.
- Этапный независимый аудит и исправление найденных проблем — нативный Pi на
  `openai-codex/gpt-6-sol`, **не** Codex CLI. Проверка читающего reviewer не
  заменяет офлайн-gate committed SHA из чистого клона.
- Основной агент координирует границы задач, проверяет diff/staging, делает
  локальные commits и ведёт критерии плана; один writer на checkout одновременно.
- Не переключай writer на другой provider молча. Timeout или connection error
  сами по себе не доказывают исчерпание лимитов; условие резервного маршрута
  подтверждается владельцем отдельно. Не запускай live/платные вызовы Polza
  без явного разрешения и лимита расходов.
- Область этого репозитория — **только генерация изображений**. Speech/voice,
  STT/TTS и другие аудио-модальности принадлежат **отдельному приложению**: здесь
  они не реализуются и не планируются, T00–T07 в очереди E00–E11 отсутствуют.
  Справочный план речи удалён из `docs/plans/` (содержимое остаётся в истории Git)
  и не открывает задач; границы — `docs/plans/release-scope.md`, change note `CN-03`.
