# WORKFLOW — Нативные Pi-сабы aimedia

- Основной агент и нативный Pi `worker` для кодирования используют
  `openai-codex/gpt-6.1-sol`. DeepSeek в текущем режиме исключён; автоматически
  возвращаться к нему нельзя — только по новому указанию владельца.
- Независимый аудит — свежий read-only Pi `reviewer` на
  `openai-codex/gpt-6.1-sol`, **не** Codex CLI. Собственные исправления интегратора
  также требуют независимого review; чтение reviewer не заменяет офлайн-gate
  committed SHA из чистого клона.
- Сложные развилки решает нативный Pi `oracle` на `openai-codex/gpt-6-astra`
  (точный ID модели в реестре). Подключай его по конкретной проблеме, а не для
  дополнительного слоя согласования каждой мелкой правки.
- Рабочая единица — законченный полезный пользовательский набор, а не отдельное
  поле/документ/receipt. Один consolidated offline gate, независимый review и
  commit на связную поставку; обязательные security/negative checks не ослабляются.
  Внутри набора реализатор последовательно проверяет контракты и failures, без
  дополнительных согласований каждой мелкой правки.
- Основной агент проверяет границы задач, diff/staging и evidence, делает
  локальные commits; один writer на checkout одновременно. Перед передачей
  checkout другому writer останови прежний запуск и сохрани незавершённый diff.
- Не переключай модель или provider молча. Timeout или connection error не
  разрешают резервный маршрут; изменение подтверждает владелец. Все маршруты
  выше — нативные Pi-агенты, не внешние CLI. Live/платные вызовы Polza — только
  с явным разрешением и лимитом расходов.
- Область этого репозитория — **только генерация изображений**. Speech/voice,
  STT/TTS и другие аудио-модальности принадлежат **отдельному приложению**: здесь
  они не реализуются и не планируются, T00–T07 в очереди E00–E11 отсутствуют.
  Справочный план речи удалён из `docs/plans/` (содержимое остаётся в истории Git)
  и не открывает задач; границы — `docs/plans/release-scope.md`, change note `CN-03`.
